# Screenshots

Drop the images referenced by the main README here, using exactly these filenames:

| File               | What to capture                                                                 |
| ------------------ | ------------------------------------------------------------------------------- |
| `home-dark.png`    | Home page in dark mode — navbar, genre sidebar and a full grid of game cards     |
| `home-light.png`   | The same view in light mode, so the theme toggle is visible in the README        |
| `game-detail.png`  | A game detail page showing the trailer, description and attributes panel         |
| `filtering.png`    | A genre + platform filter applied, with the heading reflecting it                |
| `mobile.png`       | A narrow viewport (~390px) showing the responsive single-column layout           |

Tips:

- Capture at a consistent window width (1440px works well) so the images line up in the README tables.
- Scroll so a few complete rows of cards are visible rather than cut off mid-card.
- Pick a well-known game with a trailer and good artwork for the detail shot — it reads better than an obscure title with placeholder images.
